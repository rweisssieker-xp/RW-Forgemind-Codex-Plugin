# Guided Start

Primary journey: **Discover**

Select one path and invoke only the named specialist after the user confirms or the intent is clear.

- **Ship a feature:** `structured-feature` for a bounded change; use `implementation-plan` first when scope or risk is high.
- **Fix a bug:** `systematic-debugging`, then `verification-gate`.
- **Prepare a release:** `release-readiness-score`, `rollback-planner`, then `finish-branch`.

State the selected path, the first specialist, and the verification that will establish completion. Do not load unrelated specialists.
