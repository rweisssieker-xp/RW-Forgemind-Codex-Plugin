# Idea to MVP

Primary journey: **Discover**

Start with `forgemind idea-to-mvp --goal "<outcome>" --json` to capture the existing app context.

1. Inspect the app, current workflow, users, constraints, and available signals.
2. Research market alternatives when fresh external evidence is needed; label assumptions separately.
3. Generate disruptive concepts that remove or automate a meaningful workflow step.
4. Rank concepts by evidence, user value, differentiation, feasibility, risk, and time to MVP.
5. Define one MVP hypothesis, success metric, kill condition, and smallest experiment with `discovery-operations`.
6. Run `mvp-test-lab` to plan target-user, functional, accessibility, and adversarial tests before treating the concept as validated.
7. Hand off only the selected MVP to `product-scope`, `architecture-review`, `delivery-builder`, and `quality-review`.

For immediate delivery: `Use $idea-to-mvp to analyze this existing app, choose the strongest disruptive MVP, implement it, and verify it.`
