# Workflow Menu

Primary journey: **Discover**

Show available ForgeMind specialist lenses and when to use them.

## Agents

- Orchestration Flow, Delivery Orchestrator -> `delivery-orchestrator`: route, coordinate, verify, learn.
- Product Scope, Product Owner -> `product-scope`: scope, user value, acceptance criteria.
- Architecture Review, Architect -> `architecture-review`: boundaries, data flow, risk, technical shape.
- Delivery Build, Senior Developer -> `delivery-builder`: implementation, code quality, tests.
- Quality Check, QA Engineer -> `quality-review`: test plan, regression, edge cases.
- Work Planning, Scrum Master -> `work-planning`: story prep, blockers, handoff.
- Security Review, Security Engineer -> `security-reviewer`: auth, secrets, data exposure, abuse.
- Value Signals, USP AI Strategist -> `usp-ai-strategist`: AI/KI value, USP score, MVP.
- Innovation Design, Innovation Workflow -> `innovation-first-autopilot`: app-first radical USPs and MVP choice.
- Radical Design, Radical Vibe Builder -> `radical-vibe-builder`: 10x AI/KI future features.
- Release Delivery, Release Manager -> `finish-branch`: readiness, verification, release notes.

## Output

Recommend one primary agent and optional supporting agents for the user's task.
