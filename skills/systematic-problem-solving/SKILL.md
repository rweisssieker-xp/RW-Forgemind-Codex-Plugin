# Systematic Problem Solving

Primary journey: **Discover**

Make the problem observable before proposing remedies.

1. State the failure, affected users, boundary, and measurable impact.
2. Build a causal map: signals, contributing conditions, constraints, and unknowns.
3. Test root-cause hypotheses with the smallest available evidence; do not promote correlation to cause.
4. Generate corrective options that remove a cause, relax a constraint, or add a detection control.
5. Select the smallest reversible intervention, specify verification, and define rollback conditions.

Escalate safety, privacy, production, or destructive changes through the normal ForgeMind gates. For an explicitly requested fast MVP, this diagnosis may feed YOLO mode but does not weaken those boundaries.
