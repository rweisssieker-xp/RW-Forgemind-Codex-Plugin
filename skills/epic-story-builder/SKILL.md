# Epic Story Builder

Primary journey: **Design**

Turn product scope into buildable backlog.

## Artifacts

When project files are writable:

- update `docs/forgemind/epics.md`
- create story files in `docs/forgemind/stories/`
- keep each story small enough for one implementation pass plus verification

## Output

- Epic list
- User stories
- Acceptance criteria per story
- Dependencies
- Risks
- Suggested implementation order
- Test notes
- MVP cut line

## Story Format

Use:

- As a [user], I want [capability], so that [outcome].
- Acceptance criteria:
- Implementation notes:
- Verification:
- Priority:
