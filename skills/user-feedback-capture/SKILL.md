# User Feedback Capture

Primary journey: **Learn**

Use when the user says something like:

- "gut"
- "schlecht"
- "mach das naechstes Mal anders"
- "immer so"
- "nie wieder so"
- "mehr USP"
- "weniger Text"

## Feedback Format

Classify feedback as:

- good: reinforce a pattern.
- bad: record a mistake or anti-pattern.
- change: update a preference.
- idea: create a self-update proposal.

## Storage

Use project memory by default. Use global memory only for cross-project preferences.

Keep entries dated, short, and actionable.
