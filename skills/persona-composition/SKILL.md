# Persona Composition

Primary journey: **Design**

Run `forgemind compose --goal "<outcome>" --risk <low|medium|high> --json`.

Use only the roles selected by the plan. Each handoff must include artifacts, verification evidence, open risks, and one next action. Safety stops always override the composition.
