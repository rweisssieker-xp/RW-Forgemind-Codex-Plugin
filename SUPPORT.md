# Support

Use [GitHub Issues](https://github.com/rweisssieker-xp/RW-Forgemind-Codex-Plugin/issues) for reproducible bugs, portability problems, documentation corrections, and feature requests.

Include ForgeMind version, operating system, Node.js version, the command used, redacted output, expected result, and minimal reproduction. Search existing issues first. Do not include secrets or private project content.

Security vulnerabilities belong in a private [GitHub Security Advisory](https://github.com/rweisssieker-xp/RW-Forgemind-Codex-Plugin/security/advisories/new), not a public issue. Community support is best effort and has no guaranteed service level.
