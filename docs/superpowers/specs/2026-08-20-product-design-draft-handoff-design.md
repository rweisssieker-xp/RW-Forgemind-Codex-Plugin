# Product Design Draft Handoff to Design Fidelity

## Goal

An explicitly user-selected PNG generated by Product Design becomes the sole visual source for a Design Fidelity run. The selected image is versioned locally with its source identity, digest, route, viewport, control contract, screenshots, and verification receipts so that no other generated variant can silently replace it.

## Handoff Contract

`design-fidelity import-draft` accepts a local selected PNG plus required route and optional viewport. It writes:

```json
{
  "schemaVersion": 1,
  "id": "draft-<digest>",
  "source": "product-design",
  "selectedBy": "user",
  "referencePath": "design-fidelity/drafts/<id>.png",
  "sha256": "<digest>",
  "route": "http://127.0.0.1:4173/",
  "viewport": "desktop"
}
```

The image must be a local PNG supplied from the selected Product Design result. URLs, conversation ordinals, unselected variants, path escapes, and non-PNG files are rejected. The importer copies the selected image to the active artifact store and preserves its digest; later changes to the original source file cannot alter the run.

## Agent Workflow

The Product Design flow displays alternatives. The user chooses one concrete image. The Design Fidelity skill receives that file and invokes `import-draft`; it then inspects only the imported artifact, creates a control contract, implements permitted UI changes, and runs Design Fidelity against the imported draft ID.

The skill must not infer a choice from image order, prompt order, most recent generated image, a visual similarity guess, or a bare variant number without an attached/resolved selected image.

## Completion Gate

The final report links the draft ID to the visual comparison, control contract, control evidence, and safe-interaction receipts. `matched` is allowed only when every required control is evidenced and the screenshot at the recorded viewport satisfies the draft’s pixel tolerance. Missing selection or evidence is a gap, not a result.

## Safety

The import is local-only and read/copy-only. It does not publish a Product Design image, invoke a cloud API, select a variant, or perform any unsafe interaction. `--artifacts none` rejects draft import because the immutable handoff cannot be preserved.

## Acceptance Criteria

- Explicitly selected local PNG imports to an immutable digest-addressed artifact.
- An unselected/remote/non-PNG input is rejected before persistence.
- Design Fidelity resolves only the imported draft ID, not an arbitrary current PNG.
- Reports make the selected Product Design source and all control/visual receipts traceable.
- Source and Marketplace mirrors match; full CI and strict release validation pass.
