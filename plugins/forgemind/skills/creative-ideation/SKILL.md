# Creative Ideation

Primary journey: **Discover**

Start with a clear challenge, audience, constraints, and a success signal. Generate diverse options before judging them.

1. Reframe the challenge as a “How might we” question.
2. Run at least three lenses: combine, invert, remove, exaggerate, or borrow from an adjacent domain.
3. Produce 10 or more distinct ideas; avoid cosmetic variations.
4. Cluster ideas by mechanism, then score the strongest ones for user value, feasibility, differentiation, and reversible MVP scope.
5. Return a ranked shortlist with one experiment per candidate and one deliberately rejected idea.

Keep claims as hypotheses until evidence exists. If implementation is requested, hand the selected option to `yolo-feature` for a fast MVP or to the normal delivery workflow for governed execution.
