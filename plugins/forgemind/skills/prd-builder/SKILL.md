# PRD Builder

Primary journey: **Design**

Create a concise, buildable PRD.

## Artifact

When project files are writable, create or update `docs/forgemind/prd.md`. Preserve useful existing sections and append dated decisions instead of deleting prior context.

## Output

- Product summary
- Target users
- Problem statement
- Goals
- Non-goals
- Current app context
- Proposed solution
- MVP scope
- User journeys
- Functional requirements
- Non-functional requirements
- AI/KI and USP opportunities
- Risks and assumptions
- Success metrics
- Open questions

Prefer concrete requirements over vague intent. Include AI/KI USP notes when relevant.
