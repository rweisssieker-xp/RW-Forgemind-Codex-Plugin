# Presentation Architecture

Primary journey: **Release**

Design for a decision, not for slide count.

1. State the audience, decision, available time, and credibility requirements.
2. Build a narrative arc: tension, insight, proposal, evidence, trade-offs, and requested action.
3. Give every slide one job and one takeaway; remove decorative slides.
4. Mark claims as observed, inferred, or proposed, and attach proof or a validation plan.
5. Add a concise demo script, anticipated objections, and a decision-ready closing slide.

Use visuals to clarify relationships. Do not create a dashboard-shaped deck when a compact narrative is sufficient.
