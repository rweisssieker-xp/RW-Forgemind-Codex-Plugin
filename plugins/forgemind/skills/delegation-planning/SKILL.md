# Delegation Planning

Primary journey: **Design**

Run `forgemind delegation --goal "<outcome>" --budget <1-8> --json`.

This creates a local plan, not an autonomous executor. Assign only independent tasks in parallel; preserve safety, evidence, and approval boundaries in every handoff.
