# Human-Centered Design

Primary journey: **Design**

Work from observed user evidence whenever available; label assumptions clearly when it is not.

1. Define the user, situation, job, pain, and current workaround.
2. Separate observations, inferences, and open questions.
3. Write a focused problem statement and success criteria.
4. Diverge on solution concepts, then select the smallest prototype that can invalidate the riskiest assumption.
5. Specify who will test it, the task they will attempt, the expected behavior, and the signal that changes the decision.

Do not confuse a polished mockup with validation. Preserve accessibility, consent, and privacy constraints in every prototype.
