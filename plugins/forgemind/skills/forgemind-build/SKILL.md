# Build

Primary journey: **Build**

Invoke the Delivery Engine (`delivery-orchestrator`) to select the smallest sufficient specialist. Inspect first, define acceptance criteria, implement a bounded change, verify it, review risk, and report evidence. Use `yolo-feature` only when the user explicitly asks for the fastest bounded MVP.
