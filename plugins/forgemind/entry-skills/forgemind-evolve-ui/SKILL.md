# ForgeMind Evolve UI

Run `forgemind evolve-ui`. If the command is unavailable, run `node <installed-plugin-root>/bin/forgemind.mjs evolve-ui`. Use the Live Application Twin to select a workflow, preserve the existing UI, and create a reversible experiment with visual, accessibility, functional, and rollback evidence.
