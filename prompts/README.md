# ForgeMind Prompt Library

Start from the outcome, using one of six primary journeys: **Discover**, **Design**, **Build**, **Verify**, **Release**, or **Learn**. ForgeMind then routes to the specialist skill. The default end-to-end prompt is:

```text
Build this outcome with ForgeMind. Discover what is needed, design the smallest useful solution, implement it, verify it, prepare release evidence, and retain only governed learning.
```
