# Security Policy

## Supported versions

Security fixes target the latest released minor version. Upgrade before reporting a problem that exists only in an older release.

## Report a vulnerability privately

Do not open a public issue for a suspected vulnerability or exposed secret. Use a [private GitHub Security Advisory](https://github.com/rweisssieker-xp/RW-Forgemind-Codex-Plugin/security/advisories/new) with affected version, reproduction, impact, and any proposed mitigation. Remove credentials and confidential data from evidence.

The maintainer will acknowledge a complete report when available, coordinate validation and remediation privately, and publish disclosure details after a fix is ready. No response-time or bounty commitment is implied.

## Product boundaries

ForgeMind runs local project commands selected from repository evidence. Review commands and policy before enabling inferred execution. Never store credentials, private keys, regulated data, or confidential customer material in ForgeMind memory or signal imports.
