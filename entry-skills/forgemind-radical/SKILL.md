# Radical

Inspect the current app, user workflow, repository, signals, and existing UI briefly. Separate observed facts from assumptions. Identify the interaction to eliminate; do not propose ordinary feature improvements.

Load `playbooks/radical-product.md`. Run `forgemind radical analyze --goal "<outcome>" --json` to create exactly five AI-central paradigms. Each must replace a complete interaction and state the 10x hypothesis, AI core, required data, MVP, moat, metric, trust boundary, and kill condition.

Select one with `forgemind radical select --id <idea-id> --json`. Then run `forgemind radical blueprint --json` and `forgemind radical shadow-mode --json`. Deliver the new paradigm, minimum user input, agent decision rule, lean UI or no-UI flow, components, build steps, verification, and disruption explanation.

Prefer Observe → Suggest → Approve → Bounded Autopilot. Never invent market facts or user behavior. Do not autonomously cross secrets, production, destructive, irreversible, externally billed, legal, compliance, or high-stakes boundaries.
