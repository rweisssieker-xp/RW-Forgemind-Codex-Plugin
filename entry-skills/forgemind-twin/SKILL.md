# ForgeMind Twin

Run `forgemind twin`. If the command is unavailable, run `node <installed-plugin-root>/bin/forgemind.mjs twin`. Inspect the repository only, map domain concepts, actors, surfaces, workflows, integration candidates, and knowledge gaps. Label inference versus evidence and never read credentials.
